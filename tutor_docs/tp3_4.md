# TP 3 — Manipulation 4 : théorème de Thévenin

## Objectif (fascicule p. 8-9, table 9 lignes R_Th / I_Th)
Remplacer le réseau vu de la charge par son équivalent de Thévenin :
E_Th = V₀ (manip 1) et R_Th = V₀/I₀ ; le vérifier en réglant le RHÉOSTAT à
R_Th en série avec une source E_Th, puis en mesurant I_Th dans R et en
comparant au courant mesuré dans R avec le vrai réseau.

## Banc ajouté
Rhéostat 0-230 Ω (bornes RHA, RHB, curseur RHW) ; attention : courant max
≈ 1,5 A (alarme de chauffe au-delà de 90 %).

## Câblage type (équivalent Thévenin alimenté par E1)
E1+ → RHA ; RHW → A1 ; A2 → A+ ; A− → RLa ; RLb → B1 ; B2 → E1−
(la source E1 joue le rôle de E_Th réglée à V₀, le rhéostat joue R_Th).

## Méthode
1. Calculer R_Th = V₀/I₀ avec SES relevés de manip 1 (I₀ en ampères).
2. Régler le rhéostat à cette valeur (clic/molette ; lire la consigne Ω).
3. Régler E1 à V₀ (consigne CV), mesurer I_Th dans R (ampèremètre série).
4. Comparer I_Th au courant dans R mesuré sur le vrai réseau (manip 2/3).

## Pièges
- Rhéostat à 0 Ω + source : surintensité (alarme chauffe).
- Confondre R_Th (résistance vue des bornes, sources ÉTEINTES = ici calculée
  par V₀/I₀) avec une mesure ohmmètre directe (interdite sur circuit actif).
- Oublier que E_Th doit être réglé à V₀, pas à E1.

## Missions (statut dans le contexte)
R_Th calculé accepté (contrôle d'unité et de tolérance), rhéostat proche de
R_Th, I_Th recopié, comparaison cohérente.
