# TP 3 — Manipulation 3 : théorème de superposition

## Objectif (fascicule p. 8, table 9 lignes I₁ / I₂ / I_total)
Mesurer I₁ (E1 seule active, E2 REMPLACÉE PAR UN FIL), I₂ (E2 seule, E1
remplacée par un fil), puis I_total (les deux actives) dans la branche R, et
vérifier I_total = I₁ + I₂.

## Point clé du simulateur (à expliquer si l'étudiant bloque)
Une alimentation ÉTEINTE = sortie **OUVERTE** (relais), pas un court-circuit.
Pour « remplacer E2 par un court-circuit », il faut : éteindre E2 PUIS poser un
fil entre E2+ et E2− sur la maquette. Sinon la branche reste ouverte et le
théorème est faux.

## Câblage
- Branches 1, 2 et R complètes (comme manip 2), ampèremètre en série dans R
  (A3 → A+, A− → RLa).
- Superposition E1 seule : E2 éteinte + fil E2+–E2−. E2 seule : E1 éteinte +
  fil E1+–E1−. Total : les deux allumées, fils retirés.

## Méthode
1. Configurer chaque cas, lire l'aiguille (calibre 100 mA typique), recopier
   I₁, I₂, I_total sur la table 9.
2. Vérifier I₁ + I₂ = I_total aux incertitudes près (ΔI = 1,5 × C/100).

## Pièges
- Oublier le fil de court-circuit sur la source éteinte (erreur classique).
- Laisser le fil en place pour la mesure « total » : court-circuit franc !
- Sens de branchement de l'ampèremètre : aiguille à zéro si inversée.

## Missions (statut dans le contexte)
I₁, I₂, I_total recopiés ; somme cohérente ; fils de superposition posés/retirés.
