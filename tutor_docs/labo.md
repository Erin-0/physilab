# Le laboratoire (contexte permanent)

## La salle
- Paillasse **circulaire** au centre : les appareils sont disposés en couronne,
  face avant tournée vers le centre ; l'élève en fait le tour.
- Bureau carré à droite : **feuille de relevés** (papier) et **stylo**. Un clic
  sur le papier ou le stylo ouvre/ferme la feuille ; le papier ouvre une
  NOUVELLE feuille vierge.
- Aucun raccourci clavier de niveau : on change de TP / niveau / manipulation
  uniquement via les onglets de l'interface.

## Gestes de base (à rappeler si l'étudiant est perdu)
- **Câbler** : clic sur une borne puis clic sur une autre (la couleur du fil se
  choisit dans la palette en bas à gauche). Clic droit : annuler le fil en
  cours. Clic sur un fil : le retirer.
- **Régler un bouton / sélecteur** : clic gauche = +1 pas, clic droit = −1 pas,
  molette = pas fin, Maj+clic = pas grossier.
- **Déplacer un appareil** : appui long (~0,3 s) puis viser ; molette = faire
  tourner l'objet saisi. Un appareil câblé se débranche si on le déplace.
- **Se pencher** : Ctrl maintenu (on vient au ras de la paillasse pour lire un
  cadran). **Loupe** : touche E.
- Les appareils à aiguille se lisent œil aligné avec le miroir anti-parallaxe ;
  valeur lue = N div × calibre / 100 ; incertitude Δg = classe × calibre / 100
  (classe 1,5 ; 100 divisions) — fascicule p. 2.

## Appareils communs
- **Voltmètre analogique** : calibres 0,3 / 1 / 3 / 10 / 30 V ; R_V = 10 MΩ.
- **Ampèremètre analogique** : calibres 1 / 10 / 30 / 100 / 300 mA ; R_A = 1 Ω.
  Au-delà du calibre : aiguille en butée + voyant OL (monter de calibre).
  On commence TOUJOURS au plus grand calibre.
- **Générateur / alimentations** : toujours livrés ÉTEINTS. Un générateur
  continu éteint = sortie OUVERTE (pas un court-circuit).
- **GBF** : n'affiche que la fréquence ; l'amplitude est un bouton aveugle →
  Ue se mesure à l'oscilloscope (CH1, en divisions).
- **Oscilloscope** : aucune mesure automatique ; on compte les divisions
  (U = N div × V/DIV, T = N div × TIME/DIV, Δφ via Δx entre les traces).

## Règle pédagogique du simulateur
Aucun écran n'affiche une grandeur que le fascicule demande de MESURER.
Si l'étudiant demande « lis la valeur à ma place », rappelle la méthode de
lecture (divisions × calibre) sans donner le nombre.
